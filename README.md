# Анализ базы данных колл-центра банка

## О проекте

Этот проект представляет собой глубокий аналитический разбор базы данных звонков колл-центра. Основная цель — выявить тренды, аномалии и потенциальные зоны роста для повышения эффективности работы операторов и увеличения продажной конверсии. Анализ полностью построен на SQL-запросах к базе данных SQLite и статистической проверке гипотез.

## Структура проекта

*   `Анализ_БД_звонков_банка.ipynb` — Jupyter Notebook, содержащий все SQL-запросы, статистические тесты и визуализации.
*   `data.db` — Файл базы данных SQLite (загружается через `gdown` в ноутбуке).
*   `db_analysys.xlsx` — Итоговый Excel-файл сแดшбордами и выгрузками данных для отчёта.
*   `requirements.txt` — Список зависимостей.
*   `README.md` — Данный файл.

## Ключевые вопросы и этапы анализа

В ходе исследования были проанализированы следующие аспекты:

1.  **Сборка единой витрины данных**: Все разрозненные таблицы базы данных были объединены в одну общую витрину с помощью `LEFT JOIN` для комплексного анализа.

2.  **Расчёт ключевых KPI**:
    *   Общее количество успешных звонков.
    *   **Продажная конверсия**: Рассчитана как отношение успешных звонков к сумме успешных и отказов.
    *   **Средняя длительность коммуникации**: Проанализирована для успешных и неуспешных звонков.

3.  **Анализ факторов, влияющих на результат звонка**:
    *   **Длительность звонка**: С помощью t-теста было установлено, что статистически значимой разницы в средней длительности между успешными и неуспешными звонками нет. Визуальный анализ показал, что затягивание разговора **более 3-5 минут** не приводит к увеличению конверсии.
    *   **Знак зодиака оператора**: Обнаружена статистически значимая взаимосвязь между знаком зодиака оператора и продажной конверсией. Операторы-«Стрельцы» показали наивысшую конверсию, а «Тельцы» — наименьшую.
    *   **Тип продукта**: С помощью теста хи-квадрат выявлена зависимость результата звонка от предлагаемого продукта. Продукты 1, 3 и 4 продавались успешнее, чем продукт 2.

4.  **Анализ эффективности операторов и подразделений**:
    *   Были определены операторы и группы с самой высокой и низкой продажной конверсией. Лидирующие позиции заняли управления **"Керса"** и **"Хирса"**.
    *   Выявлено, что операторы, работающие в **вечернее/ночное время** и в **выходные дни**, показывают значительно более высокую конверсию.

5.  **Поиск аномалий и трендов**:
    *   **Время суток и день недели**: Обнаружено, что в ночное время (с 18:00 до 05:00) и в выходные дни продажная конверсия выше.
    *   **Аномалии в данных**: Выявлены системные аномалии, такие как отсутствие времени окончания для определённых типов задач и пропущенные `task_stage_id` для источника "CM".
    *   **"Утилизация" клиентов**: Анализ показал, что по пятницам и субботам клиенты реже начинают пользоваться купленными продуктами.

## Как запустить проект

1.  **Клонируйте репозиторий.**
2.  **Установите зависимости:**
    ```bash
    pip install -r requirements.txt
    ```
3.  **Запустите Jupyter Notebook** `Анализ_БД_звонков_банка (1).ipynb`. Ноутбук автоматически загрузит необходимую базу данных `data.db` с Google Drive.
4.  Выполните ячейки для проведения анализа. Результаты будут сохранены в файл `db_analysys.xlsx`.
